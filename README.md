# IBM i Watsonx RAG Assistant

## Overview

AI-powered Retrieval-Augmented Generation (RAG) platform designed to support IBM i modernization initiatives and enterprise knowledge management.

The solution enables developers, analysts and business users to search technical documentation, RPG knowledge bases, operational procedures and enterprise documents using natural language.

---

## Business Problem

Organizations running IBM i systems often have decades of accumulated knowledge spread across:

- PDF documents
- Technical manuals
- RPG source code documentation
- Operational procedures
- Internal knowledge bases

This project aims to make that knowledge instantly accessible using AI-assisted retrieval and reasoning capabilities.
